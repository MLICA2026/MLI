👀 Before exam day

The same procedure applies to every level. Screenshots in the source use A1 Mid as an example.

One code — Zoom host role + oral courseware

927145

The oral exam questions live inside the platform courseware and are ready in your exam-day class session. Unlock them with code 927145. You can also preview the listening / reading / writing parts.

The preview link opens the quiz preview on the MLI platform (login required). The real exam is taken online by the students. Use the CO · CE · EE tabs and full-screen toggle to move through the parts.

🗓️ On exam day

  1. Claim the host role with host key 927145.
  2. Turn on the Waiting Room.
  3. Admit one student at a time; keep the others in the waiting room.
  4. When a student is finished, move them out and admit the next one.

The exact Zoom steps (also in Section 2.4):

🎤 Run & grade

  • Unlock with 927145 and share your screen.
  • Étudiant (Student) mode — present each task: draw the lottery, start the timer.
  • Examinateur (Examiner) mode — fill the rubric, then Export PDF or record the EO score (see grading below).
Do not share the code with students

Code 927145 is for teachers only.

The Phase 2 Final now uses TCF-format questions — the reduced format above (Q1–20; Tasks 1 & 2; same day) — which eases students into the full TCF. CLB5 sits this same Phase 2 Final. Phase 3 is the same as CLB6 and CLB7 (full TCF).

CLB5 — arrangement

It depends on the teaching staff. With one teacher, the whole exam can be run and graded in a single day. With two teachers, split the exam by section — each teacher runs and grades their own part, and the sections can go in parallel on the same day.

CLB6 / CLB7 — arrangement

  • The exam is split over 2 days.
  • Format closely follows the full TCF exam.
  • The Day 1 / Day 2 schedule is confirmed by the academic team.
CLB6 / CLB7 — nothing extra to prepare

All four skills come straight from the TCF bank. CO / CE are auto-graded and EE uses the TCF rubric, so there is nothing special for teachers to prepare — only the oral (EO) teacher prepares, using the TCF EO set for the level (see Oral question sets).
