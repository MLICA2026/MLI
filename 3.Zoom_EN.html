Zoom

Recording, screen sharing, annotating and the host role.

Before you start

Install the Zoom desktop application on your device. The web version does not always have the same functions.

🔴 Recording

  • Zoom recording starts automatically when you open it.
  • Recordings are uploaded to the platform's Recordings section.
  • Recordings stay available for 7 days.

To open Zoom: in Lessons, click Join Live Session → Join Zoom, then Open zoom.us / Join from the Zoom Workplace app. If the app doesn't open, download and install it, then click Join again.

🖥️ Screen sharing

Always check “Share Sound”

Without it, students will not hear audio from videos, listening exercises, recordings, or your shared screen.

When you share, pick the screen or window, then tick Share sound (and Optimize for video sharing for videos) before clicking Share.

✏️ Annotating

While sharing, use the annotation toolbar to write on the screen. Tools include text, brush, mark/highlight, and eraser, plus undo/redo and the trash icon to clear everything.

🚪 Host & waiting room

You need the host role to run the oral exam and to manage the waiting room.

Host code

The host code is sent to teachers before the test. For oral exams, the same code unlocks the courseware — see Section 3.

Claim the host role

  1. Click Participants in the Zoom toolbar.
  2. At the bottom, open More (Plus) and choose Claim host / Revendiquer le rôle d'hôte.
  3. Enter the host key and click Revendiquer.

Activate the waiting room

  1. Open Participants → More (Plus).
  2. Choose Activate waiting room / Activer la salle d'attente.

Move a student to the waiting room

  1. Hover the student, then click More (Plus).
  2. Choose Put in waiting room / Mettre en salle d'attente.

Admit a student back

Click Admit / Admettre next to the student's name in the waiting room.
